# Valid Anagram

**Topic:** Arrays and Hashing  
**Difficulty:** Easy  
**Language:** Python  
**Concept:** Hash Map / Frequency Counting

## 1. Problem Statement

Given two strings `s` and `t`, determine whether `t` is an anagram of `s`.

An anagram is formed by rearranging all the original letters exactly once.

Both strings must contain the same characters with the same frequencies.

s = "anagram"
